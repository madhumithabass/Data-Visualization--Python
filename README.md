# Data Visualization Using Python

## 📌 Project Overview
This project focuses on exploring and visualizing datasets using Python. It demonstrates how to transform raw data into meaningful visual representations to identify patterns, trends, relationships, and insights.

## 🎯 Objectives
- Understand data through visual representations.
- Identify trends, patterns, and outliers.
- Analyze relationships between different variables.
- Create meaningful charts and graphs.
- Improve data interpretation and analysis skills.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Visualization Techniques

1. **Line Plot** – Visualize trends over time.
2. **Bar Chart** – Compare values across categories.
3. **Histogram** – Understand data distributions.
4. **Scatter Plot** – Identify relationships between variables.
5. **Box Plot** – Detect outliers and understand data spread.
6. **Pie Chart** – Represent categorical proportions.
7. **Heatmap** – Visualize correlations between variables.
8. **Count Plot** – Display frequency distributions.
